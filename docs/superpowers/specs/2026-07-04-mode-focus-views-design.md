# モード特化ビュー & 追加GTFSフィード（ちゅうバス）設計

日付: 2026-07-04 / 承認: ユーザー（会話にて）

## 目的

1. 鉄道・バス・船・空・索道の各交通モードに「特化ビュー」を追加する。
   路線・駅などの地物やパネルのラベルからリンクで遷移し、そのモードだけが
   視点・スタイルを最適化した状態で表示される。
2. gtfs-data.jp に存在しないちゅうバス（府中市、京王バス受託）を取り込む。

## 1. モード特化ビュー（同一SPA + URLハッシュ）

- ルート: `#/`（全体表示・従来動作）と `#/mode/rail|bus|ferry|air|ropeway`
- `hashchange` 監視で切替。URL共有・ブラウザ戻る/進む対応。
- 新モジュール `web/src/modes.ts` にモードプリセットを定義:
  - **rail**: 鉄道路線＋駅のみ。線幅×2・駅×1.5、mode別色を鮮明化。
    年代スライダー・車両アニメは継続利用可。カメラは現在ビュー中心へ寄る。
  - **air**: 空路＋空港のみ。日本全体俯瞰（zoom≈4.5）。アーク不透明度↑・幅↑。
  - **ferry**: 航路のみ。列島全体の海域中心（zoom≈5.5）。線幅×2・発色↑。
  - **bus**: バス路線＋停留所のみ（自動遅延ロード）。都市圏スケール。不透明度↑。
  - **ropeway**: 索道のみ。pitch強めで山岳が見える視点。線幅↑。
- `buildTransitLayers(data, state, tooltip, era, focus?)` に focus パラメータを
  追加。focus時は該当モードのレイヤーのみ強調スタイルで構築。
- リンク入口:
  - 左パネル: 各モードラベル横に「→」リンク。モード中はパネルに「← 全体表示」。
  - ツールチップ: 地物クリックでピン留め（pointer-events有効化）し、
    「▶ ○○モードで見る」リンクを表示。featureのmodeから遷移先を判定。
    駅クリックの発車標とは共存させる。

## 2. 追加GTFSフィード機構（ちゅうバス）

- ちゅうバスのGTFSは ODPT「京王バス / Keio Bus」(keio_bus_all_lines) に
  含まれる。公共交通オープンデータ基本ライセンス・無料ユーザー登録が必要。
  https://ckan.odpt.org/dataset/keio_bus_all_lines
- 要登録のため自動DLせず、`data/raw/extra-gtfs/*.zip` に手動配置した
  GTFS zip を bus.ts が既存 `processFeed()` で処理してマージする。
- 取得手順・ライセンス表記を SETUP.md に明記（一次ソース・ライセンス明示）。
- 取り込み後にちゅうバス系統の存在を検証。含まれない場合は代替ソースを再調査。
